# Playbook: Documentation & Production Runbooks

> **Binding Authority**: Part 14.54, Part 20.33, Part 22.24 & AGENTS.md  
> **Scope**: User guides, developer documentation, deployment runbooks, and disaster recovery.

---

## 1. Documentation Requirements
Every new platform capability requires documentation across three tiers:
1. **User Documentation (`/docs`)**: Getting Started, Project Workspaces, Uploading Artifacts, Preflight Engines, Evidence Inspection, Reports, and Cloud ALM Integration.
2. **Admin Documentation**: Organization Administration, Enterprise Security, SSO/SCIM, API Keys, Webhooks, and Landscape Management.
3. **Technical Reference**: Official CLI (`erp-preflight`), Model Context Protocol (MCP) server, REST API specifications, and CI/CD quality gate integration.

---

## 2. Production Runbooks (`docs/runbooks/`)
- Hostinger VPS & Coolify deployment procedures.
- Database backup restoration and disaster recovery verification.
- Emergency key rotation and credential revocation runbook.
- Knowledge snapshot publishing and shadow evaluation verification.
